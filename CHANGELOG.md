# История версий PBX Doc

Номер версии и дата выпуска показываются в подвале каждой страницы
(`src/Core/Version.php`). Каждый выпуск изменений увеличивает версию на 0.01.

## 0.27 — 14.11.2026

- Номера, вкладка «Внешние»: отборы по типу, провайдеру, транку и
  подразделению; вкладка «Внутренние»: по подразделению и отделу. Отборы
  работают вместе с живым поиском, сохраняются в адресе страницы и
  учитываются в выгрузках (Excel, PDF, CSV для MikoPBX). В каждом отборе
  есть вариант «не указан».
- Исходящие маршруты: АОН маршрута при сохранении присваивается полю «АОН»
  внутренних номеров маршрута (состав для «Внутренние номера», номера
  подразделения для «Подразделения»), изменения пишутся в журнал номеров.
  Если АОН маршрута не «Городской»/«Сотовый» — показывается предупреждение.
- Карточка внутреннего номера: подсказка, каким исходящим маршрутом задан
  АОН; при смене АОН вручную, если он задаётся маршрутом, — предупреждение
  и подтверждение «Всё равно сохранить выбранный АОН».

## 0.26 — 14.11.2026

- Параметр `APP_TIMEZONE` в `.env` — часовой пояс приложения. По нему же
  выставляется часовой пояс сессии MySQL, так что время записей и журнала
  изменений совпадает со временем приложения независимо от настроек
  сервера БД.
- Подразделения: поле «Приветствие оператора» (перед «Описанием», такого
  же размера).
- Список номеров, вкладка «Внутренние»: колонка «Отдел» после
  «Подразделения».
- Импорт CSV: подразделения и отделы, которых нет в справочниках, больше
  не считаются ошибкой — они сгруппированы в блоке «Нет в справочниках —
  создать?», отмеченные создаются при импорте.
- Миграция `0011_department_operator_greeting.sql`.

## 0.25 — 13.11.2026

- Экспорт внутренних номеров с типом «Внутренний» в CSV для импорта
  сотрудников в MikoPBX (формат «стандартный», 13 полей): кнопка
  «CSV для MikoPBX» на вкладке «Внутренние» (`/extensions`), с учётом
  поиска. number ← «Номер», user_username ← «Владелец»; sip_secret,
  sip_dtmfmode, sip_transport, sip_enableRecording — одинаковые для всех
  номеров; остальные поля пустые. На вкладке показывается
  предупреждение, если у части номеров не заполнен «Владелец».

## 0.24 — 13.11.2026

- Внутренний номер с типом «Внутренний»: поле «Отдел» (справочник «Отделы»).
- Карточка отдела: номера отдела, сгруппированные по типам, с выгрузкой в
  Excel/PDF (как на карточке подразделения). На карточке подразделения у
  внутренних номеров появилась колонка «Отдел».
- Импорт внутренних номеров (тип «Внутренний») из CSV: шаблон файла,
  экран проверки с ошибками и дублями; для каждого дубля — «Дополнить
  недостающие», «Заменить все данные» или «Пропустить».
- Миграция `0010_extension_division.sql`.

## 0.23 — 09.11.2026

- Новый справочник «Отделы» (`/divisions`): наименование и описание.
- Внутренний номер с типом «Внутренний»: поле «АОН» — пусто или внешний
  номер «Городской»/«Сотовый», выбор через поиск от 3 цифр. На карточке
  внешнего номера показано, у каких внутренних номеров он выбран АОН-ом.
- Карточка подразделения: все номера подразделения, сгруппированные по
  типам.
- Выгрузка списков номеров в Excel (.xlsx) и PDF — с карточки
  подразделения и со страницы `/extensions` (текущая вкладка с учётом
  поиска). Для PDF добавлена библиотека tFPDF и шрифт DejaVu (`lib/tfpdf/`).
- Миграция `0009_divisions_and_caller_id.sql`.

## 0.22 — 23.10.2026

- Calltracking: цели вынесены в подчинённый справочник «Цели»
  (`/calltracking/goals`). У подразделения может быть несколько целей —
  они выбираются из выпадающих списков, новую цель можно создать прямо в
  форме подразделения.
- Список `/calltracking`: подразделение и его цели через запятую; каждая
  цель — ссылка на карточку цели, где видно, в каких подразделениях (и у
  каких номеров) она используется.
- Цели, которые раньше вписывались вручную, перенесены в справочник
  миграцией `0008_calltracking_goals.sql` (одинаковые тексты объединены).
- В подвале страницы появились номер версии и дата выпуска.

## 0.21 и ранее

Выпуски до введения нумерации версий (патчи 0001–0009: справочники
подразделений, оборудования, юрлиц, провайдеров, музыки и Calltracking;
очереди и группы обзвона; маршрутизация; визуальный конструктор сценариев;
провайдер и «Емкость СЛ» у транков).
